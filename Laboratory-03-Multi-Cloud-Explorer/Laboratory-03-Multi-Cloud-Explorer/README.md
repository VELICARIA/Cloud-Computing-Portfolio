# Laboratory 3: Multi-Cloud Explorer

## Mission Overview
This laboratory activity is part of the CCM101 - Cloud Computing course under the College of Information Technology, University of Eastern Pangasinan. As a member of the Cloud Evaluation Team at CloudNova Technologies, my task is to explore three of the world's leading cloud platforms — Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP) — and recommend the most suitable provider for different business scenarios.

## Objectives
- Explore the major public cloud platforms
- Identify the core services offered by AWS, Azure, and GCP
- Compare cloud services across different providers
- Analyze business requirements and recommend appropriate cloud solutions
- Create professional technical documentation using Markdown
- Continue developing a well-organized GitHub Cloud Computing Portfolio
