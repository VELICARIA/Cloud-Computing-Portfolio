# AWS Research

## Brief Overview
Amazon Web Services (AWS) is the cloud computing platform operated by Amazon, launched in 2006. It is widely recognized as the market leader in cloud services, giving businesses on-demand access to computing power, storage, databases, and other resources over the internet instead of requiring physical hardware. AWS currently offers well over 200 services covering categories such as compute, storage, networking, databases, machine learning, and security.

## Global Infrastructure
AWS infrastructure is organized into geographic **Regions**, each containing multiple isolated **Availability Zones (AZs)** with independent power, cooling, and networking. This setup allows applications to stay online even if one AZ experiences an outage. Beyond standard Regions, AWS also offers **Local Zones** (which bring compute closer to major cities for lower latency) and **Wavelength Zones** (which embed AWS compute at the edge of 5G telecom networks).

## Cloud Management Console
The **AWS Management Console** is the web-based dashboard used to create, configure, and monitor AWS resources. It provides a visual interface for services like EC2 and S3, alongside tools such as AWS CloudShell (browser-based command line) and the AWS Cost Explorer for tracking spending.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud)** – Provides resizable virtual servers ("instances") for running applications.
2. **Amazon S3 (Simple Storage Service)** – Object storage used for files, backups, and media, known for high durability.
3. **Amazon RDS (Relational Database Service)** – A managed service for relational databases such as MySQL and PostgreSQL, handling backups and patching automatically.
4. **Amazon VPC (Virtual Private Cloud)** – Lets users create an isolated network environment to control how their AWS resources connect to each other and the internet.

## Three (3) Advantages
1. **Pay-as-you-go pricing** – Businesses only pay for the resources they actually use, avoiding large upfront hardware costs.
2. **Global scalability** – Applications can expand into new regions worldwide within minutes instead of building new data centers.
3. **Extensive service ecosystem** – A very broad catalog of tools (AI/ML, analytics, IoT, etc.) means most technical needs can be met within a single platform.

## Typical Enterprise Use Cases
- Hosting scalable web and mobile applications
- Running data backup and disaster recovery systems
- Big data processing and analytics
- Training and deploying machine learning models
